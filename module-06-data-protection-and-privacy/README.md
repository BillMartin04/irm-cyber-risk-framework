# Module 6: Data Protection & Privacy

{% hint style="success" %}
**4LOD Alignment:** 2nd Line (Data Governance & Compliance Policy)
**Primary Persona:** Data Protection Officers, Privacy Analysts, InfoSec Policy Leads
{% endhint %}

## What this module covers

**Data Protection, Classification, and Privacy Governance.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Translating data privacy laws into technical controls.
- Structuring enforceable data classification standards without stalling operational speed.

## Module deliverable

> Develop an Enterprise Data Classification Policy and a complete Privacy Impact Assessment (PIA) template.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
