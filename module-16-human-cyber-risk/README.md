# Module 16: Human Cyber Risk

{% hint style="success" %}

## What this module covers

**Human Cyber Risk, Culture, and Behavioral Metrics.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Measuring true human risk metrics beyond click rates.
- Building sustainable security culture across distributed organizations.

## Module deliverable

> Develop a 12-Month Security Culture Roadmap and a Security Champions Program Charter.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
