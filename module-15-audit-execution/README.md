# Module 15: Audit Execution

{% hint style="success" %}
**4LOD Alignment:** 3rd Line (Independent Assurance & Internal Audit)
**Primary Persona:** Internal Auditors, External IT Audit Specialists, Assurance Managers
{% endhint %}

## What this module covers

**Cyber Security Audit Execution and Evidence Assurance.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Conducting formal control audits.
- Writing defensible, executive-grade audit findings.
- Managing external auditors effectively.

## Module deliverable

> Complete a formal Control Assessment Workpaper with fully documented TOD/TOE testing results.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
