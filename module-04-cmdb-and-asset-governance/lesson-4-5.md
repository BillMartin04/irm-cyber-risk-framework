## Read

Decommissioning governance closes the loop that discovery opens. Hardware disposal must produce a certificate of destruction. Software decommission must revoke licences and remove access. Cloud decommission must terminate IAM roles and delete keys. Data decommission must satisfy retention and legal-hold obligations before deletion.



## Apply

- Write a one-page decommissioning standard covering hardware, software, cloud, and data.

## Done When

- Every asset retirement produces the same three artefacts: disposal certificate, access revocation record, data disposition attestation.
