# Module 4: CMDB & Asset Governance

{% hint style="success" %}
**4LOD Alignment:** 1st Line (Operational Ownership & IT Assets)
**Primary Persona:** Enterprise Architects, CMDB Administrators, IT Operations Leads
{% endhint %}

## What this module covers

**IT Asset Management and CMDB Governance.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- CMDB as the single source of truth for risk assessments.
- Calculating impact based on asset criticality rather than arbitrary ratings.

## Module deliverable

> Create an Asset Criticality Scoring Matrix linked directly to business function dependencies.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
