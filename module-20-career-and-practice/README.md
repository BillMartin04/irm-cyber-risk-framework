# Module 20: Career & Practice Building

{% hint style="success" %}
**4LOD Alignment:** Professional Practice (Advisory Enablement)
**Primary Persona:** Freelance Consultants, Advisory Firm Founders, Career Switchers
{% endhint %}

## What this module covers

**Career Acceleration, Advisory Positioning, and Practice Building.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Packaging specialized GRC knowledge.
- Positioning oneself as an indispensable enterprise advisor.
- Winning high-value consulting contracts.

## Module deliverable

> Build a personal GRC Consulting Portfolio, Service Catalog, and Statement of Work (SOW) template.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
