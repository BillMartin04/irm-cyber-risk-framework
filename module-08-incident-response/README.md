# Module 8: Incident Response

{% hint style="success" %}
**4LOD Alignment:** 1st Line (Incident Responders) & 4th Line (Crisis Leadership)
**Primary Persona:** Incident Responders, SOC Managers, Business Continuity Planners
{% endhint %}

## What this module covers

**Threat Detection, Incident Response, and Crisis Governance.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Establishing governance over incident handling.
- Designing realistic executive tabletop exercises.
- Integrating post-incident lessons into control updates.

## Module deliverable

> Produce an Incident Response Playbook and a facilitation guide for a C-Suite Ransomware Tabletop Simulation.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
