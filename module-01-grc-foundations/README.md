# Module 1: GRC Foundations

{% hint style="success" %}
**4LOD Alignment:** 4th Line (Governing Body) & 2nd Line (Risk Oversight)
**Primary Persona:** Aspiring GRC Analysts, IT Auditors, Junior Risk Officers
{% endhint %}

## What this module covers

**Foundations of Cyber Security Governance, Risk, and Compliance.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Clear distinction between governance oversight, risk decisions, and regulatory baselines.
- Operational friction points between security and business units and how to design them out.

## Module deliverable

> Design an organizational GRC charter and a cross-functional stakeholder responsibility matrix.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
