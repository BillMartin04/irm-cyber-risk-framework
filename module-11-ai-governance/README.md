{% hint style="success" %}

## What this module covers

**AI Governance, LLM Security, and Emerging Tech Risk.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Applying governance to Generative AI deployments.
- Assessing model risk and data-privacy exposure.
- Complying with evolving global AI regulations.

## Module deliverable

> Produce an Enterprise Generative AI Acceptable Use Policy and an AI System Security Risk Assessment checklist.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
