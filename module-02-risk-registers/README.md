# Module 2: Risk Registers

{% hint style="success" %}
**4LOD Alignment:** 2nd Line (Risk Management Oversight)
**Primary Persona:** Risk Analysts, Information Security Managers, Compliance Specialists
{% endhint %}

## What this module covers

**Enterprise Risk Identification, Assessment, and Registers.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Deep mechanics of risk scoring matrices.
- Structuring actionable risk registers.
- Handling formal risk exception requests without creating audit vulnerabilities.

## Module deliverable

> Construct an end-to-end dynamic Risk Register with automated scoring formulas and exception-handling workflows.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
