# Module 10: FAIR Quantification

{% hint style="success" %}
**4LOD Alignment:** 2nd Line (Quantitative Risk) & 4th Line (Board Capital Decisions)
**Primary Persona:** Senior Risk Analysts, Quantitative Modelers, CISO Advisors
{% endhint %}

## What this module covers

**Cyber Risk Quantification with FAIR.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Translating technical vulnerabilities into probable financial loss ranges.
- Using financial data to justify cyber security budget requests.

## Module deliverable

> Model a realistic data-breach scenario using quantitative calculations to present annualized loss exposure.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
