# Prerequisites and Tools

## Accounts

- **ServiceNow Personal Developer Instance (PDI)** — free, from [developer.servicenow.com](https://developer.servicenow.com). You will use it for hands-on modules (CMDB, IRM, Vulnerability Response).
- **GitHub account** — to fork the [Lumina Cyber Risk repo](https://github.com/BillMartin04/lumina-cyber-risk) and this course repo.
- **YouTube account** — to watch the lesson videos on the [TechTalk with Bill channel](https://www.youtube.com/@techtalkwithbill).

## Tooling

- A spreadsheet tool (Excel or Google Sheets) — for the Unified Control Framework and Risk Register deliverables.
- A diagramming tool (Lucidchart, Draw.io, Miro) — for the architecture and 4LOD diagrams.
- A markdown editor — for policy and charter drafts.

## Optional

- A **ServiceNow IRM-enabled instance** — many enterprise learners will already have one at work. If not, the concepts are demonstrated on Lumina.
- A **cloud sandbox account** (AWS, Azure, or GCP) — for the cloud governance module.
