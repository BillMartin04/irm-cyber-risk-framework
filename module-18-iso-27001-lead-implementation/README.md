# Module 18: ISO 27001 Lead Implementer

{% hint style="success" %}
**4LOD Alignment:** 2nd Line (Lead Implementation) & 3rd Line (Independent Audit)
**Primary Persona:** Lead Implementers, Lead Auditors, Quality Assurance Directors
{% endhint %}

## What this module covers

**ISO/IEC 27001 Lead Implementation and Audit Masterclass.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Leading an organisation through complete ISO 27001 ISMS preparation, documentation, internal audit, and formal certification.

## Module deliverable

> Draft a comprehensive Statement of Applicability (SoA) and an ISO 27001 Internal Audit Program.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
