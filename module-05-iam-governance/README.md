# Module 5: Identity & Access

{% hint style="success" %}
**4LOD Alignment:** 1st Line (Access Control Execution) & 2nd Line (Policy Oversight)
**Primary Persona:** IAM Engineers, Directory Services Admins, Access Governance Officers

## What this module covers

**Identity Governance and Access Management (IAM).** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- IAM controls as primary audit targets.
- Establishing zero-trust identity baselines.
- Running defensible user-access certification campaigns.

## Module deliverable

> Design a Privileged Access Management policy and a quarterly User Access Review procedure.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
