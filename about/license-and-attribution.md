## How to cite this course

The repository ships a machine-readable [`CITATION.cff`](https://github.com/BillMartin04/irm-cyber-risk-framework/blob/master/CITATION.cff) file. GitHub renders it as a **"Cite this repository"** button on the repo homepage.

### Recommended citation (APA style)

Martin, B. (2026). *Cyber Risk & GRC Architect Masterclass* (Version 1.0.0) [Open educational resource]. GitHub. https://github.com/BillMartin04/irm-cyber-risk-framework
