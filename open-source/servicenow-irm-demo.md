# ServiceNow IRM Demo Environment

## Personal Developer Instance (PDI)

Every ServiceNow-native lesson in this course can be followed on a free **Personal Developer Instance (PDI)** from [developer.servicenow.com](https://developer.servicenow.com). Sign up, request an instance, and note that PDIs hibernate after ~10 days of inactivity — wake yours before each session.

## IRM plug-ins to enable

For the full course experience, activate:

- **Governance, Risk, and Compliance** — the IRM plug-in.
- **Policy and Compliance Management**.
- **Risk Management**.
- **Vendor Risk Management** (for Module 9).
- **Advanced Risk** (for KRI / continuous monitoring, Module 12).
- **Regulatory Change Management**.

Some of these require a specific request or entitlement — check the current PDI catalogue for details.

## Update sets

The [Resources → ServiceNow Update Sets](../resources/servicenow-update-sets.md) page will grow with course-specific update sets — starter Risk Framework, Sample Authority Documents, and the 4LOD role model — as they are published.
