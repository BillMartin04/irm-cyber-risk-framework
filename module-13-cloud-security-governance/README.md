# Module 13: Cloud Security Governance

{% hint style="success" %}
**4LOD Alignment:** 1st Line (DevSecOps Execution) & 2nd Line (Cloud Policy Baselines)
**Primary Persona:** Cloud Security Architects, DevSecOps Leads, Infrastructure Compliance Engineers
{% endhint %}

## What this module covers

**Cloud Security Governance and Multi-Cloud Compliance.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Governing infrastructure across diverse cloud providers.
- Implementing policy-as-code to prevent non-compliant infrastructure deployments.

## Module deliverable

> Create a Multi-Cloud Compliance Matrix and a Cloud Security Baseline Configuration Policy.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
