## Read

The CIS Critical Security Controls (v8) provide a prioritised, prescriptive set of eighteen controls that a resource-constrained organisation can implement in order and materially reduce cyber risk. Where NIST CSF describes what a program should cover and ISO 27001 describes how to run the management system, CIS Controls describe what to do first.

For advisors, CIS is the framework you reach for when a mid-market client says 'we have no security program, where do we start'.
