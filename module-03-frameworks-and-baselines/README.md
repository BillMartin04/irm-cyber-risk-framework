# Module 3: Frameworks & Baselines

{% hint style="success" %}
**4LOD Alignment:** 2nd Line (Control Frameworks & Compliance)
**Primary Persona:** Security Architects, GRC Consultants, Compliance Engineers
{% endhint %}

## What this module covers

**Security Frameworks, Standards, and Baseline Mapping.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Practical application of the major security frameworks.
- Techniques to eliminate duplicate audit overhead through unified control mapping.

## Module deliverable

> Build a Unified Control Framework (UCF) that maps one internal control to NIST CSF 2.0, ISO 27001, and SOC 2.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
