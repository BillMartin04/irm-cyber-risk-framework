# Module 9: Third-Party Risk

{% hint style="success" %}
**4LOD Alignment:** 2nd Line (Vendor Risk Oversight)
**Primary Persona:** Vendor Risk Analysts, Procurement Specialists, Third-Party Risk Managers
{% endhint %}

## What this module covers

**Third-Party and Supply-Chain Risk Management (TPRM).** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- End-to-end vendor assessment lifecycles.
- Translating vendor security responses into risk treatments.
- Managing supply-chain dependencies.

## Module deliverable

> Build a Third-Party Vendor Risk Assessment Intake Workflow and a Vendor Security Scoring Rubric.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
