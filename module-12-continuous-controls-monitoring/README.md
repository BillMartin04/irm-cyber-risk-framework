## What this module covers

**Continuous Controls Monitoring (CCM) and GRC Automation.** By the end of this module you will have added a specific, portable capability to your GRC practice — one that you can demonstrate on an interview, deploy in a client engagement, or promote inside your own organisation.

## Key takeaways

- Transitioning organizations from static spreadsheet compliance to dynamic, automated, continuous control validation.

## Module deliverable

> Map a technical control to an automated testing script and construct a continuous control-health dashboard.

Every lesson in this module builds toward that deliverable. Complete every lesson before submitting the deliverable.
