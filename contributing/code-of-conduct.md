# Code of Conduct

This is a professional, inclusive community for GRC and cyber-risk practitioners. Contributors and readers are expected to:

- Be respectful and constructive.
- Focus criticism on the material, not the person.
- Assume good faith.
- Refuse harassment of any kind.

Report violations to the maintainer via the [TechTalk with Bill YouTube channel](https://www.youtube.com/@techtalkwithbill).
