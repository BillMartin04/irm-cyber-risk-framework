# Roadmap and Issues

## Roadmap

- **Video production** — each lesson pairs with a short YouTube video. Videos are being produced module-by-module and embedded here as they land.
- **Template gallery** — downloadable Markdown / DOCX / XLSX templates published alongside each module.
- **ServiceNow update sets** — packaged reference configurations under [Resources → Update Sets](../resources/servicenow-update-sets.md).
- **Translations** — Thai, and other languages as contributors step forward.

## Filing issues

Use the [GitHub Issues tab](https://github.com/BillMartin04/irm-cyber-risk-framework/issues) to report broken links, factual errors, or lesson improvement suggestions.
